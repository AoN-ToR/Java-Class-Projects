*TURN BASED 3v3 FANTASY COMBAT*

**Main play**
Each player selects a class 3 characters, alongside one item and one ability for each of them. They then battle it out in a 3v3 turn based combat.

**Charater's differences**
Each character's stat are decided by their class (Warrior, Mage, Ranger, Healer, Golem, Rogue), altough items, abilities and move may have an effect on them or other things.

**How the order is decided**
The attack order is decided based on character speed at the beginning of each turn.
Effects like poison and leftovers take place at the end of turn.

**How to win**
When all opposing characters are down (0hp), you win the game ! But careful not to be defeated before that... Some might prefer spamming the strongest attacks, while others will try to stack up stat boosts instead. Find the style (and characters) that suits you !
